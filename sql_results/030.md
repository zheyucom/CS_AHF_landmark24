**NT-proBNP 不能作为主队列纳入标准的必要条件**，否则会丢掉绝大多数人。它可以作为：

1. AHF 早期支持证据；
2. 扩展模型变量；
3. 敏感性分析变量；
4. “是否检测 NT-proBNP”这个测量过程特征。

早期 IV loop diuretic 使用 stay 数 = 6792
HF ICD 候选队列总数 = 14877
比例约 45.7%

| 变量                      | 含义                         | 用途              |
| ------------------------- | ---------------------------- | ----------------- |
| `iv_loop_rx_early_flag`   | 早期有 IV loop diuretic 医嘱 | AHF 支持证据      |
| `iv_loop_emar_early_flag` | 早期有实际给药记录           | 更强 AHF 支持证据 |
| `iv_loop_any_early_flag`  | 两者任一为 1                 | 最终规则可用      |

| 数据类型           | 推荐做法                                                     |
| ------------------ | ------------------------------------------------------------ |
| 生命体征           | 用官方 `vitalsign` 的 itemid、单位转换、范围限制，重新聚合 0–24 h |
| GCS                | 用官方 GCS，但论文说明镇静处理                               |
| 尿量               | 用官方 `urine_output`，按 0–24 h、24–48 h、48–72 h 重新聚合  |
| 血气 / 乳酸 / HCO3 | 用官方 lab/bg/chemistry 或官方 itemid，限定 Blood/Plasma/Serum |
| BNP / NT-proBNP    | 自定义，只用 Blood NT-proBNP itemid 50963                    |
| IV loop diuretic   | 自定义，优先结合 prescriptions + emar                        |
| 血管活性药/强心药  | 优先用官方 medication concepts                               |
| overt CS outcome   | 自定义，但尽量基于官方 vasoactive + lactate + urine output + MAP/SBP |
