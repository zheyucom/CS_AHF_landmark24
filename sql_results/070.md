建模阶段对 NEE 特征做 winsorization / robust scaling 即可。

| 项目         | 定义                                                         |
| ------------ | ------------------------------------------------------------ |
| 主队列       | AHF + early sepsis12，12 h landmark，无 pre12 overt CS       |
| 预测窗口     | ICU 入科 0–12 h                                              |
| 预测时长     | 12–60 h，未来 48 h                                           |
| 主结局       | hemodynamic deterioration                                    |
| 主结局组成   | 新启用血管活性/强心药、药物种类增加、NEE 较 pre12 max 增加 ≥0.05、或 12–60 h 死亡 |
| 主结局事件率 | 334 / 2424 = 13.78%                                          |

这个缺失结构是可以接受的，但建模时要注意：

- `lactate_max` 缺失较高，必须保留 `lactate_available_flag`；
- `ph_min` 缺失较高，必须保留 `ph_available_flag`；
- `nee_0_12h_max` 缺失高是合理的，因为只有使用升压药时才有 NEE，建模时不要简单当作随机缺失。建议把缺失填 0，同时保留 `nee_available_0_12h_flag`。
