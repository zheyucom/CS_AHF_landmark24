# 知识卡 04｜竞争风险模型的评价与报告

> 来源：第 4 课（2026-09-15）· 项目：CS_AHF 血流动力学恶化预测
> 本卡基于你自己的 `analysis_r/091_evaluate_finegray_oof_v33.R` 与真实产物撰写。

## 一句话本质

模型评价是两个独立维度：**判别**（会不会排序，AUC）与**校准**（说 20% 是不是真的 20%，校准曲线 + Brier）；竞争风险下两者的计算口径都要改。

## 核心概念

- **判别 vs 校准**：AUC 相同的两个模型，校准可以完全不同（预测值整体缩放不影响 AUC）。两者必须分别报告。
- **time-dependent AUC**：竞争风险下按各时点 CIF 排序计算，配合 IPCW 处理截尾。解读：随机取一个事件患者与一个非事件患者，模型给前者更高风险的概率。>0.70 可接受，>0.80 良好。
- **Brier score**：预测概率与观测结局的均方误差（越低越好），竞争风险下用 IPCW 加权。**单看没有意义，必须与空模型（null model）比较**。
- **skill score / IPA**：`1 − Brier/Brier_null`，模型相对"只会猜平均风险"的改善幅度。
- **校准曲线（十分位）**：按预测风险分位分组，比较"组内平均预测 CIF"与"组内观测 CIF"，落在对角线上为完美校准。
- **`Hist(time, status) ~ 1`**：`prodlim` 的多状态响应格式，用于表达事件/竞争/截尾三态；`Surv()` 表达不了。

## R 代码模板

```r
library(riskRegression); library(prodlim)

score <- Score(
  object   = list(primary = cif_pred, sensitivity = cif_pred2),
  formula  = Hist(time, status) ~ 1,     # 多状态响应（不是 Surv）
  data     = data.frame(time = time, status = status),
  cause    = 1,                          # 只评"恶化"这个原因
  times    = 48,
  metrics  = c("auc", "brier"),
  plots    = "calibration",
  null.model = TRUE,                     # 用于算 skill score
  conf.int = TRUE, se.fit = TRUE         # 报告 95% CI（务必打开）
)
score$AUC$score; score$Brier$score; score$Calibration$plotframe
# IPA / skill score
1 - score$Brier$score[model == "primary"]$Brier /
    score$Brier$score[model == "Null model"]$Brier
```

## 项目实测结果（v3.3，OOF）

- 判别：48h time-dependent AUC = **0.762**
- 校准：Brier **0.0652** vs 空模型 0.0724 → skill score ≈ **10%**
- 十分位校准（n≈555/组）：

| 组 | 预测 CIF | 观测 CIF | 判读 |
|---|---|---|---|
| 1 | 1.62% | 1.26% | 略高估 |
| 2–7 | 2.6%–7.9% | 3.4%–8.6% | 略低估（+0.3–0.8 pp） |
| 8 | 10.03% | 9.71% | 基本一致 |
| 9 | 13.58% | 13.51% | 几乎完美 |
| 10 | 26.06% | 24.10% | 高估约 2 pp |

结论：偏差多在 1 个百分点以内，**校准良好**（校准好比 AUC 高更难得，是论文卖点）。

## 审稿人视角的 6 个补强点

1. **AUC/Brier 缺 95% CI**（`conf.int/se.fit` 现为 FALSE）→ 打开并报告 `0.762 (95% CI …)`。
2. **低风险组事件数极少**（第 1 组 ≈7 个事件）→ 观测 CIF 的 CI 很宽，需说明或附 CI。
3. **两套校准口径并存**（`Score(plots="calibration")` 的 plotframe + 自算十分位 `cuminc`）→ 论文只报一套，写明口径，避免正文与补充材料数字不一致。
4. **缺临床效用分析（DCA / net benefit）** → ICU 预测模型论文的常见必备项。
5. **skill score 未显式报告** → 写成 `1 − Brier/Brier_null ≈ 0.10`。
6. **仅 48h 单时点 AUC** → 补 12/24/36/48h 的 time-dependent AUC 曲线作为稳健性证据。

## TRIPOD 报告清单（对应本项目素材）

- 预测时点与靶人群（48h CIF；T12 landmark 后 AHF index ICU stay）
- 样本量与事件数（n=5,555；事件 454；竞争 2,935；截尾 2,166）
- 内部验证方式（5 折 CV，按结局×脓毒症分层）
- **预处理在折内完成**（训练折中位数 + 均值/SD）← 加分项，务必写明
- 判别（含 CI）+ 校准（曲线 + Brier + 空模型对比）
- 缺失值处理（折内中位数；4 个高缺失指标走敏感性）
- 软件与包版本（脚本已自动 `sessionInfo`）
- 不把表观性能当性能估计

## 一句话总结

"我们报告了判别与校准两个维度：AUC 0.762 说明排序能力可接受，Brier 相对空模型改善 10%、十分位校准贴合对角线说明**绝对风险估计可靠**——后者恰恰是预测模型最需要的能力。"

## Methods 段落模板（评价部分）

> Discrimination was assessed using time-dependent AUC at 48 h, and calibration using decile-based calibration plots (mean predicted vs observed cumulative incidence within each decile) and the Brier score, benchmarked against a null model (IPA / Brier skill score). All metrics were computed on out-of-fold predictions from the 5-fold cross-validation, with 95% CIs obtained by bootstrap resampling. Because the lowest-risk decile contained few events, calibration estimates in that stratum should be interpreted with caution. Analyses used riskRegression and prodlim in R 4.x.
