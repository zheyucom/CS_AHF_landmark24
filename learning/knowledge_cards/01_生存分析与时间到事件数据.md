# 知识卡 01｜生存分析与时间到事件数据

> 来源：第 1 周第 1 课（2026-08-27）· 项目：CS_AHF 血流动力学恶化预测

## 一句话本质

临床结局往往不是"有/没有"，而是"多久发生"——生存分析就是处理"到某个结局发生的时间"这类数据的统计框架。

## 核心概念

- **时间到事件数据（time-to-event）**：每个患者记录的不是简单结局，而是 (随访起点, 事件是否发生, 发生时间/删失时间) 的三元组。
- **删失（censoring）**：随访结束时事件未发生（失访、转院、研究截止）。删失 ≠ 没发生，只是"还没观察到"。
- **风险集（risk set）**：某时刻 t 仍然"有资格"发生事件的患者集合（未发生事件、未删失、未出局）。它是生存概率计算的分母，随时间逐减。
- **KM 曲线（Kaplan-Meier）**：只在事件时刻下降的阶梯曲线，逐时刻把"存活比例"相乘得到。删失不影响曲线高度，只减少后续分母。
- **log-rank 检验**：比较两组 KM 曲线是否有统计学差异。注意：只回答"有没有差异"，不给出效应大小。
- **Cox 比例风险模型**：h(t) = h₀(t)·exp(βX)。不假设基线风险形状，但假设"协变量效应是倍增且不随时间变化"——即 PH 假设。
- **PH 假设检验**：cox.zph() 用 Schoenfeld 残差检验；p<0.05 视为违反，常用分层或时间交互项处理。

## R 代码模板

```r
library(survival)

# 数据长这样：time=到事件/删失的时间，status=1事件 0删失，group=分组
fit_km <- survfit(Surv(time, status) ~ group, data = df)
summary(fit_km)
plot(fit_km, col = c("#A32D2D","#185FA5"), xlab="时间(h)", ylab="生存概率")

# log-rank 检验
survdiff(Surv(time, status) ~ group, data = df)

# Cox 回归
fit_cox <- coxph(Surv(time, status) ~ age + sofa + group, data = df)
summary(fit_cox)     # HR 与 95%CI
cox.zph(fit_cox)     # PH 假设检验，p<0.05 说明违反
```

## 项目应用（CS_AHF）

- 项目结局是三态结构：**事件**（血流动力学恶化 / ICU 内死亡，463 例）、**竞争**（活着离开 ICU，2,935 例）、**截尾**（T60 仍无事件，2,166 例）——这就是多状态时间到事件数据。
- 为什么不能用普通二分类 Logistic：
  1. 丢失"何时发生"的信息（T13 恶化与 T47 恶化预后含义不同）；
  2. 提前离开 ICU 者不能当作"无事件"（观察不完全）；
  3. 竞争事件存在时，KM/普通 Cox 会系统性高估事件风险。
- 因此主分析选择 Fine-Gray 竞争风险模型（第 3-4 周系统学）。

## 易错点与审稿人常见问题

| 常见错误 | 后果 | 应对 |
|---|---|---|
| 删失当"没发生" | 低估事件率 | 用 KM/Cox 正确处理删失 |
| 竞争事件当删失 | 高估事件率 | 竞争风险模型（Fine-Gray） |
| 不检验 PH 直接报 HR | 审稿人必问 | cox.zph + 分层/时间交互敏感性 |
| 只看二分类结局 | 丢时间信息 | 时间-事件分析 |

## 一句话总结

"结局不只是'发生了没有'，而是'多久发生'；删失不是没发生，竞争不是删失——这就是我们选择时间到事件分析、并最终采用竞争风险模型的原因。"
