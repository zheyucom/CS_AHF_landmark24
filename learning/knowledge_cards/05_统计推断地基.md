# 知识卡 05｜统计推断地基：抽样、标准误、置信区间与 P 值

> 来源：第 5 课（2026-09-15）· 模块一「统计推断地基」开篇
> 本卡是理解后续所有课程的底座——项目里每个数字都带着不确定性。

## 一句话本质

统计推断只解决一件事：**在只掌握样本的情况下，量化"我的估计有多不确定"**。三个工具：标准误（SE）→ 置信区间（CI）→ P 值，再加一个通用的 bootstrap。

## 核心概念

- **抽样变异性**：同一研究重复做 100 次，每次算出的均值/HR/AUC 都不同。这是推断统计的起点。
- **SD vs SE（必须分清）**：
  - SD 描述**个体之间**的差异（数据属性）；
  - SE 描述**估计值本身**有多稳（估计量属性），等于"重复抽样分布"的标准差。
  - `SE = SD/√n` → 样本量翻 4 倍，SE 才减半。
- **95% CI 的正确含义**：重复抽样 100 次，约 95 次算出的区间会覆盖真值。
  - ❌ 不是"真值有 95% 概率落在这一次的区间里"（真值固定，不随机）。
  - CI 提供两类信息：**效应大小**（区间位置）+ **精度**（区间宽度）。
- **P 值的定义**：原假设为真时，观测到"至少这么极端"结果的概率。
  - ❌ 不是效应为真的概率；❌ 不是效应大小；❌ 不是结果可靠度；❌ 不等于临床重要性。
  - `P < 0.05` ⇔ 95% CI 不含无效值（HR/sHR=1）。**CI 信息严格更多，应优先报告。**
- **显著 ≠ 重要**：本项目 `age sHR 1.019`（不显著）、`bun_max sHR 1.148`（显著但效应量不大）——显著与否取决于**精度**，不取决于**重要性**。
- **多重比较 / winner's curse**：检验 45 个纯噪声变量，按 α=0.05 期望仍有 2–3 个"显著"；被 P 值挑中的变量效应量被系统性高估，这是**外部验证衰减**的重要来源。
- **bootstrap**：把样本当总体，有放回重抽 B 次（通常 1000），得到统计量的经验分布，取 2.5%/97.5% 分位为 95% CI。适用于 AUC、Brier、校准点、IPA 等无简单公式的指标。
- **患者级重抽样（cluster bootstrap）**：同一患者有多条记录（多个 ICU 段/多次住院）时，必须按**患者**整组重抽；按行重抽会造成伪独立 → SE 低估、CI 过窄、P 值过小。

## R 代码示例

```r
# 1. 系数型指标：直接用 SE 构造 CI（无需 bootstrap）
sHR <- exp(fit$coef)                       # cmprsk::crr 系数
se  <- sqrt(diag(fit$var))
ci  <- exp(fit$coef + c(-1, 1) * 1.96 * se)

# 2. 复杂指标：患者级 cluster bootstrap
set.seed(20260915)
ids <- unique(dat$patient_id); B <- 1000; out <- numeric(B)
for (b in seq_len(B)) {
  pick <- sample(ids, length(ids), replace = TRUE)
  boot <- do.call(rbind, lapply(pick, function(i) dat[dat$patient_id == i, ]))
  out[b] <- compute_metric(boot)           # 如 time-dependent AUC
}
quantile(out, c(0.025, 0.975))             # 95% CI
```

## 项目应用：四个具体动作

| 动作 | 做法 |
|---|---|
| AUC / Brier 补 CI | 患者级 bootstrap（B=1000），或 `Score(conf.int = TRUE, se.fit = TRUE)` |
| 校准十分位补 CI | 组内 bootstrap；最低风险组仅 ≈7 个事件，CI 会很宽，必须报告 |
| 主模型 sHR 的 CI | 已有方差矩阵，`exp(coef ± 1.96*SE)` 直接算 |
| 重抽样单位核对 | 确认建模数据是否"每患者一行"；否则改用 cluster bootstrap / cluster-robust SE |

## 与开题稿的对应（答辩可直接讲）

| 开题稿的表述 | 统计原理支撑 |
|---|---|
| "不以单因素 P 值筛选" | 多重比较 + winner's curse + 遗漏变量偏倚 |
| "不根据院内外部结果调整变量或阈值" | 防止过拟合与选择性报告 |
| "重抽样单位为患者" | cluster bootstrap，避免伪独立导致 CI 偏窄 |
| "预处理/调参均在训练折内完成" | 防止信息泄露（第 10 课展开） |
| "决策曲线须与竞争事件处理一致" | 竞争风险 DCA 必须基于 CIF（第 12 课展开） |

## 建议补强

缺失机制敏感性中应区分两类情况：
1. **该做的检验没做**（可能 informative missingness——病情轻或临终患者化验少，缺失本身与结局相关，接近 MNAR 边界）；
2. **记录了但值缺失**（更接近 MAR）。
两类需分开讨论（第 8 课展开）。

## 一句话总结

"我的所有结果都是**估计值**：报告点估计的同时给出 95% CI，是承认不确定性；用患者级重抽样，是保证这个不确定性没有被低估。"
