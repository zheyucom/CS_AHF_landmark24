## 二、缺失值处理：已明确（规则完整度最高）

来源：`project_control/MISSING_DATA_AND_ECHO_HANDLING_PLAN_V1.md` + 决策登记表 D 节。

**四类缺失分类**：

| 类型 | 判定 | 处理 |
|---|---|---|
| 结构性缺失 | 药物/支持治疗无记录 = 未暴露 | 填 0**仅当变量字典明确**，并保留记录指示器 |
| 测量性缺失 | 可能测了但窗口内无有效结果 | **折内 MICE（最终 m=20，PMM）**；不得填正常值 |
| 信息性缺失 | 是否测量本身携带病情信息 | 保留 `measurement_available` 指示器，必做敏感性 |
| 检查选择性缺失 | 心超/胸片/CT 未做 | **禁止数值插补**，记为 `not_done/unavailable` |

**已验证的关键事实**：检测可用性与三态结局强相关——主事件组乳酸有效测量率 67.84%（308/454），竞争事件组 45.66%（1,340/2,935）。因此缺失指示器敏感性分析是**必做**而非可选。

**可行性运行**：5 折外层 + 每折 m=5：MICE only AUC 0.7533 / Brier 0.06533；MICE+指示器 0.7566 / 0.06490。

**禁止事项**（已成文）：全量先插补再 CV、把 T12 后信息放进插补模型、不可把心超缺失插补为"无异常"。

## 三、`>xx` / `<xx` 截断值：规则已明确，但**实测存在高风险陷阱**

### 3.1 已定义的规则（登记表 B 节）

| 形态 | 字段 | 规则 |
|---|---|---|
| `>xx` | `censor_type=right_censored`, `lower_bound=xx` | 不得记作 `xx`，不得乘倍数；描述统计报"至少为 xx"；建模用 `log1p(lower_bound)` 作保守代理 + `right_censor_flag=1` + 敏感性比较 |
| `<xx` | `censor_type=left_censored`, `upper_bound=xx` | **不得记作 0**；阈值判断仅在整区间位于阈值一侧时成立（`<1` 可判低于 2；`<3` 不能） |
| `xx-yy` / 范围 | `interval_censored` + 上下界 | 不强行取中点；必须入模时预先指定代理并做敏感性 |

### 3.2 实测证据（本院原始检验数据，2026-09-16 扫描）

```
女性检验记录（42,129 行）：截断值 3,115 行（7.4%）
  NT proBNP：截断 857 / 24,705（3.5%），形态全部为 ">25000"
男性检验记录（85,740 行）：截断值 8,150 行（9.5%）
  NT proBNP：截断 2,181 / 50,149（4.4%），形态 ">25000"、"<20"、"<20.00"
```

**实测样例（注意第三列）**：

| 检验指标 | 检验结果值 | 检验结果数值 |
|---|---|---|
| NT proBNP | `>25000` | **空** |
| NT proBNP | `<20` | **空** |
| 超敏肌钙蛋白I | `<0.01` | 空 |
| 肌钙蛋白I | `>50` | 空 |
| 脑钠肽BNP（正常） | `225.8` | `225.8` |

### 3.3 为什么这是本项目最危险的一处

**当值为 `>xx` 或 `<xx` 时，导出表的 `检验结果数值` 列为空字符串。**

因此：

1. 若脚本直接采用 `检验结果数值`，**`>25000` 的最危重患者会被判为"缺失"**；
2. 随后进入 MICE 或中位数插补 → 被插补到中位数水平（通常 1,000–2,000 pg/mL 量级）；
3. 结果是**真正风险最高的人群被系统性抹平到中等水平**——这不是随机缺失，而是**由检测上限造成的、与病情严重程度强相关的信息性缺失**；
4. 后果：模型在最高风险段最不准，方向性偏倚（把最危重的人群标错），且校准曲线在高风险十分位出现高估（实测第 10 组预测 26.1% vs 观测 24.1%，与此类机制可能有关，需专门核验）。

**登记表 B 节的规定正是为防这一点**（"不得把它当作 xx，也不得随意乘倍数"），但**尚未落到代码**。

## 六、给研究者的建议动作（可立即执行）

1. **先确认三项决定**（尤其第 2 项 BNP 规则）——这是队列冻结的前置条件；
2. 在 BNP 进主模型前，先产出**截断值专项统计**（按时间窗、按指标、按三态结局分组），量化 `>25000` 患者在结局上的分布；
3. 对 `>25000` 组**必须做三种处理的敏感性对比**：① 保守下界代理 `log1p(25000)` + 指示器；② 分箱（如 >25000 单列一档）；③ 排除（仅作偏倚诊断）。**三种结果方向一致才可放心报告**；
4. 统一解析函数并加单测（含 `>25000`、`<20`、`<0.01`、空值、"溶血"等文本样例）；
5. 补出变量字典（含单位、范围、缺失语义），否则结构性缺失填 0 的规则无法合法执行。

## 七、与方法学课程的衔接

本案例是**信息性缺失（informative missingness）**的教科书级实例：

- 缺失不是随机的，而是由**检测上限**（assay 上限）导致，且与**病情严重程度正相关**；
- 这类缺失近似 **MNAR**（非随机缺失），标准 MICE 的 MAR 假设不成立；
- 正确处理不是"换个插补算法"，而是**保留删失语义 + 指示器 + 多种代理策略的敏感性分析**；
- 论文必须报告截断比例与处理方式（TRIPOD 要求），否则外部验证时本院与 MIMIC 的 BNP 分布不可比。

对应课程：模块一第 8 课《缺失数据机制与插补（MCAR/MAR/MNAR、MICE、折内处理）》。
