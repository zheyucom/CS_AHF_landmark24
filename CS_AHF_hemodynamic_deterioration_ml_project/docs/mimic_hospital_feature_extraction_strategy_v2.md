# MIMIC 与院内数据提取策略 v2

## 总体路线

当前不建议等所有新特征都完成后再做院内工作。更稳妥的路线是两条线并行：

1. 用当前 MIMIC v2 top80 模型做院内字段映射，判断是否可以先开展外部验证。
2. 在 MIMIC 和院内同步推进高价值增量特征，再分别重跑 MIMIC 内部验证和院内外部验证。

这样做的好处是：如果院内已经能覆盖当前模型，就能尽早得到外部验证结果；如果部分字段缺失，也能明确是“当前模型可验证但需删减变量”，还是“必须先补抽关键动态数据”。

## 当前 MIMIC 心超结论

本机 mimiciv31 数据库没有 `mimiciv_note`、radiology、discharge 或 echo report 文本表。

结构化表可直接提取：

- TTE/TEE 检查发生记录：`mimiciv_icu.procedureevents`，itemid 225432/221255。
- 少量心输出量/心指数：`mimiciv_icu.chartevents`，itemid 220088、224842、228368、228369。

结构化表暂不能可靠提取：

- LVEF：`d_items` 里有 `Ejection Fraction` itemid 227008，但当前库 `chartevents` 审计为 0 条。
- RV dysfunction、瓣膜病、肺动脉压、舒张功能：需要心超报告文本或结构化超声系统字段。

因此，MIMIC 现阶段能先做 `081A` 结构化 echo availability 审计，但真正的 LVEF/RV dysfunction 需要后续安装 MIMIC-IV-Note 或使用院内心超系统/报告文本。

## 什么情况叫“院内字段提不出来或定义不同”

1. 时间粒度不同
   MIMIC 常有逐条 `charttime/starttime/endtime`，院内可能只有日期或班次汇总。解决：优先导出原始长表；若只有区间汇总，保留区间开始/结束时间用于按 overlap 分摊。

2. 医嘱不等于实际执行
   袢利尿剂、升压药、强心药如果只取医嘱，会高估真实暴露。解决：优先取 eMAR/输注泵/执行记录；医嘱仅作补充审计。

3. 升压药剂量单位不统一
   NEE 需要药名、剂量、单位、体重、起止时间。解决：导出原始剂量和单位，不要只给“是否使用”；由统一脚本换算 NEE。

4. 检验 assay 和单位不同
   BNP/NT-proBNP、troponin T/I、高敏/非高敏可能不能直接混合。解决：导出项目名称、标准码、单位、参考范围、采样时间；建模前分层或标准化。

5. 动态变量被提前汇总
   MAP 低血压负荷、shock index、趋势斜率、乳酸清除率都需要原始时间序列。解决：本院尽量返回长表，后续由同一脚本生成 0-12h 汇总变量。

6. 心超文本与结构化字段差异
   如果有结构化 LVEF，优先直接用；如果只有报告文本，需要抽取并人工抽样验证。解决：导出报告时间、报告全文、检查类型、结构化 LVEF 字段、RV 功能字段。

## 院内优先请求的数据源

- ADT/ICU 入出科：患者脱敏 ID、住院号、ICU stay、入出科时间、死亡时间。
- 诊断编码：ICD 或本地诊断名称，用于 AHF、合并症和感染来源。
- 生命体征长表：HR、SBP、DBP、MAP、RR、SpO2、体温、记录时间。
- 检验长表：乳酸、血气、肌酐、BUN、电解质、血常规、凝血、BNP/NT-proBNP、troponin、CK-MB。
- 用药执行长表：升压药、强心药、袢利尿剂、抗菌药，包含起止时间、剂量、单位、给药途径、体重。
- 出入量长表：input、urine output、其他 output，包含记录时间或区间。
- 呼吸支持：有创通气、无创通气、HFNC、普通氧疗起止时间。
- 心超：检查时间、报告时间、LVEF、RV dysfunction、瓣膜病、肺动脉压、报告全文。
- 微生物/感染：培养时间、标本部位、阳性结果、感染诊断或感染来源分类。

## 返还给 Codex 做可提取性审计

请优先返还：

- `external_validation_variable_mapping_v2.xlsx` 中已回填的本院字段名、单位、时间字段和 mapping_status。
- 每个数据源 20-50 行脱敏样例长表。
- 字段字典：字段含义、单位、取值范围、缺失编码、时间精度。
- 若能导出完整 cohort 数据，则按 `hospital_external_validation_data_template_v2.csv` 或原始长表形式返回。

拿到后下一步审计：

1. 字段覆盖率：当前 top80 模型特征能覆盖多少。
2. 定义一致性：时间窗、单位、药物执行记录是否能复刻。
3. 缺失率和异常范围：是否满足模型输入质量。
4. 结局可复刻性：12-60h 支持升级、NEE 升级、死亡时间是否可逐 stay 生成。
5. 外部验证可行性：直接验证当前模型，还是先做删减版/增量版模型。
