# 开题研究设计与方法初稿

版本：2026-09-15。用于开题讨论与后续Methods写作；以下区分已执行工作和拟执行方法，不提供未经完成的研究结果。数字来源为[任务总览](RESEARCH_DASHBOARD.md)所列当前运行，文献编号见[方法依据表](METHODS_EVIDENCE_MAP_20260915.md)。

## 拟题与研究目的

**ICU失代偿性心力衰竭患者早期血流动力学恶化或死亡的预测模型：基于MIMIC的开发与内部验证及单中心外部验证。**

本研究拟在ICU入科12小时仍存活且留在ICU的失代偿性心力衰竭（decompensated heart failure，DHF）成人患者中，利用入ICU后前12小时可获得的信息，预测随后48小时内血流动力学恶化或ICU内死亡的累积发生风险。研究重点为风险识别和跨数据库可迁移性，不解释治疗的因果效应，也不将治疗升级相关恶化直接等同于新发心源性休克。

心衰是需要结合症状、体征、心脏结构或功能异常及客观充血证据判断的临床综合征。单独使用心衰编码、利钠肽升高、利尿剂医嘱或心超异常，可能将慢性稳定心衰、其他原因低氧或非心源性容量负荷混入研究对象。因此，本研究先建立可追溯的DHF操作性表型，再开发预测模型。[R1、R2]

## 设计与数据来源

采用回顾性双数据库研究。MIMIC用于模型开发与内部验证；本院数据用于锁定模型后的外部验证。每名患者原则上以首次符合预设选择过程的index ICU段作为分析单位。实际index选择需在整次住院的入ICU、出ICU及再入ICU记录链上完成核对，不能把同一住院内多个ICU段合并成一个持续住院段。

本院原始提取使用ICU相关文书、成人条件及床旁心超选择条件，男女数据已合并，且按临床确认排除了患者9204020。现有8,385人为床旁心超选择后的成人候选，不代表全院所有成人ICU患者。本院主分析进一步要求规定时间窗内床旁心超报告结果可用，胸片不作为硬纳入条件。MIMIC以多域DHF证据筛选，心超作为支持及敏感性层。两库检查选择及测量差异需在纳入流程、Table1和外部适用性讨论中报告。[R3、R8]

伦理审批、数据使用许可、知情同意豁免及研究覆盖年月，应按现有正式文件和最终数据日期范围填写。本稿不预设这些信息已经核验。

## 时间锚点与纳排

| 对象 | 操作定义 | 当前执行方式 |
|---|---|---|
| T0 | index ICU实际入科时间 | 护理明确到达记录、正文ICU到达/转入事件优先；出ICU记录入院字段作证据；普通入院/入病房不自动当ICU |
| 表型支持窗 | `[T0-24h,T0+12h)` | 允许同患者入ICU前相关报告；不同就诊号在T0后的记录不拼接到本段 |
| 预测器窗 | `[T0,T0+12h)` | 仅使用预测时点前可获得的资料；后写出院/死亡记录不回填预测器 |
| T12资格 | T12仍存活并留在index ICU | 已出ICU/死亡者不进该风险集；观察不足单独标未知 |
| 既有休克代理 | 前12h血管活性药使用且乳酸最大值>=2 | 与MIMIC现有061C/061D代码对齐；院内文书/医嘱代理单列，缺失不证明阴性 |
| 结局窗 | `[T12,T60)` | 主事件、存活离开index ICU和观察终止分别定位 |

当前不将“有IABP/ECMO”直接解释成既有061C主排除标志。是否已经处于预设结局状态、是否还能发生相对基线的循环支持升级，须结合具体终点组成单独核对。DHF证据成立与预测风险集资格是两个判定步骤。

同一住院内再入ICU需分别保存每段入口和出口，SOAP的“拟转出”只用于提示检查实际转科记录，不当作已经转出。对于时间冲突，保留来源和差异；正文相互印证的时间、上下文推定时间和结构化代理分开记录。时间代理的稳定性在敏感性分析中评价。[R3、R7、R8]

## DHF表型与文本预审核

DHF判定按三类证据组织。A域为本次HF锚点，要求当前患者、当前ICU段相关的HF诊断或与失代偿相联系的心脏结构功能异常。B域为独立失代偿表现，如呼吸困难/端坐呼吸、湿啰音、水肿、客观肺充血或与心源性机制一致的急性低灌注。C域为心超、利钠肽及患者特异性管理支持。A/B缺乏时，C域不能单独确诊。慢性心肌病、孤立BNP升高或利尿剂存在仅可作为检索入口。[R1、R2]

心超保留心室收缩/舒张、瓣膜、右心与充盈相关结果。EF正常不排除HFpEF或右心失代偿，但也不能据此直接指定HFpEF亚型。肺炎、ARDS、感染、失血、术后及肾衰等应判断能否充分解释表现；“存在替代诊断”不自动排除同时发生的心衰。

文本处理采用本地规则提取和AI原文预审核。识别否定、不确定、既往、风险告知和模板语句，保留来源文件、CSV记录行号、时间和关键原文。当前借鉴NegEx局部否定思想及CheXpert不确定标签处理，但未宣称运行了经验证的中文NegEx或将CheXpert当作DHF诊断标准。[R4、R5]

AI先完成可判定字段回填，仅将原文交叉核对后仍未决的临床问题集中交研究者。独立临床参照抽样另行标记，不能把AI与自身规则的一致性当作独立阅片一致性、患者级PPV或敏感度。阴性抽样用于检查漏检，分层抽样结果不能不加权推广为全体患病比例。[R3、R8]

## 检验、治疗与结局测量

现有检查和检验使用报告时间，不等于检查执行或标本采样时间。文书创建时间不保证内容在当时已全部写入，需要查阅正文时间及可能的后补内容。正式检查、采样时间取得后，用于重建对应的时间敏感性分支。

本院目前按用户确认以未作废医嘱作为给药执行代理，记录药物、途径、开停时间和状态。文书/SOAP用于核实适应证、治疗实施和变更；建议、拒绝治疗、空白模板不算执行。药品总量不能转换为泵速或去甲肾上腺素等效剂量（NEE）。现有资料先形成可核查的治疗组成，不等待eMAR才能继续。

主要结局为既定治疗升级相关ICU血流动力学恶化或ICU内死亡的复合终点。对支持强度阈值、相对基线变化和持续时间沿用项目结局定义，并逐项验证两库可测性。活着离开index ICU为竞争事件；T60仍在ICU且未发生事件者为行政删失。观察不完整或关键支持强度不可判定者不能默认无事件。死亡需定位到index ICU段，出ICU后的院内死亡不能直接当本段ICU死亡。[R6-R8]

## 数据清洗、测量误差与缺失值

所有清洗均在分析数据集生成前按变量字典执行，并保留原始字符串、原始单位、报告时间、异常标志、来源表及来源行号；解析值和处理理由另存，不覆盖原始记录。数值解析允许小数、负号、科学计数法及比较符号。不可解析文本（如“未测”“无法查见”“溶血”）转为缺失并记录 `missing_reason`。同一患者、同一项目、同一报告时间的重复行仅在键、时间和来源完全一致时去重，其余保留并标记重复。

单位先按项目字典和记录中的明确单位标准化。单位缺失时不进行猜测性换算；只有全库项目字典能唯一确定常规单位时，才记录 `unit_inferred_from_dictionary`、字典版本和依据。`>xx`保存下界及 `right_censor_flag`，`<xx`保存上界及 `left_censor_flag`，区间结果保存上下界；这些记录不当作精确值、0或中点。阈值判定仅在不确定区间完全位于阈值一侧时成立。BNP `>5000`只表达“至少5000”，不能单独确诊DHF。主模型若纳入右偏指标，使用预先登记的保守边界代理并设置删失指示器，同时进行删失模型/分箱敏感性分析。

异常值先按项目级生理范围和单位规则标记为 `implausible_value`，不因统计离群自动删除或Winsorize。若有确定的单位录入错误且字典支持，可进行可追溯的单位校正；无法确认时设为缺失并保留原值。临床上可能但统计上极端的值通过对数变换、限制性立方样条或稳健摘要处理。多次测量的最近值、最差值、均值或斜率必须在锁模前预先登记，不能根据结局选择。

缺失分为结构性、测量性和信息性三类。只有变量字典明确“无记录=未暴露”的结构性缺失才填0，并保留记录指示器；常规实验室和生命体征的测量性缺失采用外层训练折内的MICE（最终 `m=20`、PMM），插补模型只使用T12前可用预测变量。缺失指示器作为预设敏感性分支，完全病例仅作偏倚诊断。心超、胸片和CT属于选择性检查，不进行数值插补；未检查或结果不可用保留为 `not_done/unavailable`，并在覆盖率和选择性分析中报告。报告时间与采样/执行时间的差异通过取得正式时间后的敏感性重跑处理。

该流程依据TRIPOD+AI/PROBAST+AI的透明报告要求，以及van Buuren、White、Royston和Wood关于折内多重插补与测量缺失不确定性的建议；具体文献映射见[方法依据表](METHODS_EVIDENCE_MAP_20260915.md)。

## 模型开发与验证

主模型按既有统计方案采用Fine-Gray模型，估计存在存活出ICU竞争事件时的48小时目标事件累积发生风险。小时级person-period模型作为结构和时间分辨率补充。预测器预先依据临床意义、时点可用性、两库可迁移性和数据质量确定，不以单因素P值筛选，不根据院内外部结果调整变量或阈值。[R6-R8]

最终DHF队列和事件数确定后重新评估有效参数数、收缩需求和可支持的模型复杂度。旧候选45变量模型仅证明工程可运行，不能直接搬入更小的DHF队列。样本量评估借鉴Riley等框架并适配当前结局和竞争风险结构，不机械采用每变量10事件标准。[R9]

缺失值处理、标准化、非线性转换和调参均在训练折内完成。内部验证报告适用于竞争风险的时间依赖区分度、48小时Brier分数、校准及不确定区间；重抽样单位为患者。决策曲线须与当前风险目标和竞争事件处理一致。院内原样应用锁定模型，若进行再校准，应与原始外部验证分开报告。[R7、R8]

敏感性分析预先覆盖时间代理、同窗心超选择、严格客观证据层、缺失机制和代理给药测量，以及结局组成和持续时间。若两库无法测量等价治疗升级结局，应先明确可共同测量的终点或限制验证范围，不能将不等价代理表现称为完整外部验证。
