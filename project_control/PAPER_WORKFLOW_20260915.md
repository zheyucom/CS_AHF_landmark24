# DHF临床预测模型：开题到投稿的执行合同

版本：2026-09-16。区分“已有方法框架”“旧候选可行性运行”“最终DHF结果”。旧模型运行成功不等于最终模型完成。六步研究逻辑见[研究逻辑链](RESEARCH_LOGIC_CHAIN_20260916.md)；文献R1-R9见[对应表](METHODS_EVIDENCE_MAP_20260915.md)。标为“目标”的文件尚未生成。

研究问题：在满足多域DHF操作性表型、T12仍存活并留在index ICU的成人中，使用前12h可获得信息，预测随后48h内ICU血流动力学恶化或ICU内死亡的累积发生风险。存活离开index ICU是竞争事件。MIMIC用于开发/内部验证，本院用于锁模外部验证。

本轮已落地的工件：8,385行`cohort_disposition_working.csv`、修正后235例`priority_DHF_review.csv`、22例时间审核、7例定向语义审核及新增11例原文复核；MIMIC的300条影像审核已回连7,828份报告和5,549名候选。[开题方法正文](PROPOSAL_METHODS_DRAFT_20260915.md)已生成，最终Results尚未生成。计数和入口以[总览](RESEARCH_DASHBOARD.md)为准。

## 队列冻结的具体顺序

1. 院内先在当前时间代理下定位同窗床旁心超可用的2,599人；131人记录显示T12前已死亡/出ICU。二者可能重叠，不能直接相减当DHF分母。
2. 按互斥工作状态先审核235例；91例优先重建T12是否仍在ICU，42例明确HF锚点。其余阴性抽样与没有同窗床旁心超的敏感性队列保持可追溯。235不是最终样本量。
3. 对主队列候选逐例输出HF锚点、独立失代偿、客观/管理支持、充分替代解释、前12h休克和时间确定性；有心衰与适合预测入组分开判断。
4. MIMIC先把已审核报告用于患者层，随后补齐同窗临床与管理证据。当前675人肺充血筛查支持不是675例DHF；不能将单项报告或出院ICD直接定为本次DHF。
5. 形成带理由的最终入组与排除文件，再生成Table1、事件组成和复杂度审计；锁模后运行内部/外部验证。独立临床参照的抽样验证单独记录，不把AI重复审核当独立一致性。

## 开题的五个部分

1. 背景与目的：DHF危重患者早期风险识别；研究风险预测，不估计治疗因果效应。
2. 设计与来源：回顾性landmark竞争风险模型，MIMIC开发、本院心超选择队列验证；已完成数据整合、时间/表型预审与旧候选模型可行性。
3. 纳排与测量：成人、index段、T12存活留ICU、多域DHF、心超严格层、基线overt shock排除；明确报告时间与医嘱代理。
4. 统计路线：参数复杂度重估、折内缺失处理、竞争风险性能/校准、外部验证、预设敏感性。
5. 可行性与风险：现有数据和脚本证明工程可行性；最终DHF人数、模型性能及临床净获益待完成，不能用旧数字替代。
