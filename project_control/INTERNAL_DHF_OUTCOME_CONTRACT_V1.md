# 本院 DHF 研究一结局合同 V1

版本日期：2026-09-24

状态：`hospital_disposition_frozen_short_composite_proxy_only`

适用范围：本院接受床旁心超的成人 ICU 候选抽样框中，由 V1 操作性表型识别的 DHF 人群。

## 1. 结局层级必须分开

本合同冻结两个不同层级，不得混写：

1. **院内终末转归层**：用于研究一院内死亡负担和事件预算；
2. **T12 后 48 小时代理结局层**：用于描述本院现有医嘱/管路数据可以观察到的短期治疗升级代理，不等同于执行级临床结局。

当前没有 eMAR、逐次给药执行、泵速或 NEE，因此不能把本院医嘱层写成与 MIMIC `inputevents` 相同精度的结局。

## 2. 院内终末转归

### 2.1 权威来源

院内死亡/存活出院以同一 `visit_id` 的结构化病案首页为权威来源：

- `转归情况` 含“死亡”：`hospital_death`；
- `转归情况` 为好转、治愈、未愈或其他，且存在出院日期：`alive_hospital_discharge`；
- 缺失或不能映射：`outcome_unknown`，不得改为存活。

若同一就诊存在多版病案首页，按 `更新时间` 选择最新版。14 例存在空白/存活类别之间的版本更新，但不存在死亡与非死亡的二分类冲突。精确死亡时间只有在病案首页转归为死亡时才允许由同次就诊死亡记录补充，不能仅凭后续死亡记录反推当前住院死亡。

### 2.2 冻结结果

| 人群 | 总数 | 院内死亡 | 存活出院 | unknown |
|---|---:|---:|---:|---:|
| 主操作性表型总体队列 | 773 | 62 | 711 | 0 |
| 严格 T12 风险集 | 558 | 16 | 542 | 0 |

严格 T12 风险集的 16 例死亡均发生在离开 index ICU 之后，不得回填为 T12 后 48 小时 ICU 内死亡。

### 2.3 可采用的分析精度

病案首页提供完整终末转归，但存活出院仅有日期级时间。因此本结局可用于固定住院终点的死亡/非死亡分析；不把日期级存活出院时间冒充精确竞争事件时间。是否运行 Firth Logistic 或其他调整模型由 G5 事件预算决定，不能因数据完整就自动运行。

## 3. T12 后 48 小时代理结局

### 3.1 时间窗

- `T12=T0+12 h`；`T60=T0+60 h`；
- 观察终点为 `min(T60, index ICU outtime)`；
- 目标事件前活着离开 index ICU 为 `competing_event`；
- T60 时仍在 ICU、未观察到代理事件者为 `administrative_censor`；
- 时间、途径或升级性质不能确定者为 `outcome_unknown`。

### 3.2 药物医嘱代理

白名单与 MIMIC 合同对齐：

- norepinephrine、epinephrine、vasopressin、phenylephrine、dopamine；
- dobutamine、milrinone。

左西孟旦、异丙肾上腺素和垂体后叶素不因旧宽泛正则命中而并入白名单。

主代理层要求：

1. 途径明确含“静脉”和“泵”；普通静脉注射不算连续支持，非泵静脉滴注进入 unknown；
2. 同一药物类别相邻区间最大允许 15 分钟间隔合并；
3. 合并后持续至少 60 分钟；
4. T12 时未活动、T12 后新出现的白名单药物类别可记为 `order_proxy` 事件；
5. T12 时已有同类药物、T12 后再次开立同类医嘱时，因无泵速/NEE不能判断强化，进入 `same_class_baseline_intensity_unknown`；
6. 缺停止时间的潜在持续医嘱进入 unknown；
7. 医嘱开立时间不能写成实际给药时间。

### 3.3 机械循环支持管路代理

- T12 后新出现 IABP 或 Impella 管路记录：设备代理事件；
- ECMO 必须有不同部位、时间区间重叠的两条管路记录，事件时间取成对证据成立的较晚置管时间；
- 单条 ECMO 管路记录进入 unknown；
- 管路记录是强于计划性文书的设备存在代理，但仍与设备执行日志分层报告。

### 3.4 冻结的代理层结果

| 状态 | n |
|---|---:|
| `target_event`（代理） | 81 |
| `competing_event` | 150 |
| `administrative_censor` | 273 |
| `outcome_unknown` | 54 |

81 个代理目标事件由 78 个“新药物类别连续医嘱代理”、2 个 IABP 管路代理和 1 个成对 ECMO 管路代理构成；T12–T60 且 index ICU 转出前死亡为 0。

54 个 unknown 中，53 个来自“已有同类药物时无法判断是否强化”，1 个来自非泵静脉滴注途径不确定。另有 6 个已确认目标事件在其之前存在同药强化时间不确定；其二分类事件为阳性，但首次事件时间不可视为完全确定。

## 4. 冻结状态与禁止表述

- 院内终末转归：已通过 G4，可进入 G5 事件预算；
- 本院短期医嘱/管路代理层：已冻结为描述/敏感性层；
- 本院短期执行级复合结局：**未冻结**；
- MIMIC 执行级结局合同不因本院代理层而降级；
- 未运行任何关联模型或预测模型；
- 不得把 81 个代理事件写成 81 个经 eMAR 证实的实际治疗升级；
- 不得把 54 个 unknown 写成无事件。

## 5. 后续数据到位后的替换规则

若取得 eMAR、护理执行记录、泵速或设备运行日志，必须在不改变队列和时间窗的前提下重建执行级事件，并比较：

1. 代理阳性中执行确认比例；
2. 54 个 unknown 的重新分类；
3. 事件组成与首次事件时间；
4. 使用代理层与执行层时效应方向、校准和决策结果的变化。
