# DHF 亚型表征与异质性分析计划 v1.0

更新时间：2026-09-04 Asia/Shanghai  
状态：预设分析计划；不是新的主纳入标准，也不是治疗决策规则

## 1. 结论

左心、右心和双心受累，以及 HFrEF/HFmrEF/HFpEF 的病理生理、容量管理和治疗反应确有重要差异；它们应当进入本研究的**预设表型描述与异质性分析**。但当前不能立即拆成多个独立主预测模型：亚型定义依赖可用且时间合规的心超结果，而 MIMIC 在 `[T0-24 h,T12)` 的可用 Echo 覆盖不足；按亚型拆分还会进一步降低事件数并加重过拟合。

主研究仍预测统一的 `treatment-escalation-based ICU hemodynamic deterioration`。模型预测风险，不直接决定补液、利尿、升压或强心治疗。尤其“急性右心衰必须补液”不是可普遍套用的临床规则：容量不足时可谨慎补液，但已有静脉淤血、RV 扩张或肺血管阻力升高时，额外补液可能恶化。

## 2. 亚型在研究中的位置

| 层级 | 用途 | 是否需要完整 Echo 结果 |
|---|---|---|
| 主模型 | 全部冻结后的多域 DHF 操作性表型 | 否；MIMIC 不把 Echo 设为硬门槛 |
| 院内严格外部验证 | `echo-supported DHF ICU cohort` | 是，且结果须在 T12 前可用并支持异常 |
| 描述性分层 | 报告各亚型人数、事件、竞争出科、检查缺失和基线差异 | 是；未知者单列，不当作阴性 |
| 异质性分析 | 在主模型中加入预设亚型交互项，或做分层校准/性能 | 仅在样本和事件数足够时 |
| 亚型专属模型 | 仅探索性，须另行预先冻结低维预测器 | 需要可靠定义和足够事件，不作为当前目标 |

## 3. 推荐的表型字段

不把单一 LVEF 当作 DHF 的确诊标准。对有时间合规结果的心超，提取原始数值与文本结论，并保留检查完成、结果可用与签署时间。

| 表型 | 预设记录方式 | 解释边界 |
|---|---|---|
| HFrEF | LVEF `<=40%` | 射血分数降低表型；不单独等同 DHF |
| HFmrEF | LVEF `41-49%` | 仅在同一份/同一时间点结果可判定时分类 |
| HFpEF-compatible | LVEF `>=50%` 加舒张功能/充盈压、左房扩大、左室肥厚、肺高压或其他 HF 佐证 | 仅 LVEF 保留不能排除 HF；无其他佐证者为“LVEF 保留，HFpEF 未证实” |
| 左心受累 | 左室收缩或舒张异常、左侧充盈压升高、显著左侧瓣膜病等报告证据 | 由心超结论/结构化参数定义，不能由胸片单独替代 |
| 右心受累 | RV 收缩功能异常、RV 扩张、显著 TR、肺动脉压升高或明确右心负荷 | PE、肺高压和机械通气相关影响须记录为并存病因 |
| 双心受累 | 同时满足左、右心受累定义 | 不与“严重度”混同 |
| 未知/不可评估 | 未做、结果未在 T12 前可用、文本不可解析 | 独立报告，不插补为正常或异常 |

阈值用于研究分层的一致化，应以最终采用指南版本、心超实验室报告语义及预先冻结的数据字典复核。院内可优先使用结构化 LVEF、RV 功能、舒张功能、E/e'、LA volume、IVC、估计肺动脉压、TR 和瓣膜结论；MIMIC 若无可解析结果，不强制伪造亚型。

## 4. 分析顺序和停止规则

1. 在表型冻结后，先生成亚型可评估性表：每个亚型的总人数、可定义人数、未知人数、主事件、竞争事件和删失。
2. 主文报告总体主模型；同时按可评估亚型报告校准、48 h 风险、事件率和缺失/检查选择性。
3. 仅在每个参与交互或分层的亚型拥有足够事件、定义稳定且预先指定有限交互数时，估计 `subtype x predicted-risk` 或 `subtype x key-predictor` 交互。
4. 若任一亚型事件稀少，则只做描述性或合并为临床合理的更宽层，不训练独立模型，不报告不稳定的亚组 AUC 差异。
5. 在院内严格 Echo 队列中复现相同表型字段和分层；其角色是检验可迁移性与校准，而不是基于本院结果重选主模型。

具体“足够事件”的数值不能在看到亚型结果后临时决定。锁模前按每层事件数、候选参数数、收缩策略和 bootstrap/交叉验证稳定性共同确定；若无法支持预设低维模型，停止在描述性和交互探索。

## 5. 与肺部影像、生物标志物和血气的关系

- 心超：优先提供结构/功能和亚型信息；结果缺失是检查选择与数据覆盖问题，不作 MICE。
- 胸片和胸部 CT：提供肺水肿/肺血管充血及 PE、肺炎、ARDS 等替代或并存证据。胸部 CT 可以纳入，且在肺部鉴别中很有价值；但 CXR/CT 的完成高度选择性，因此 CXR OR CT 是肺部证据域，CXR AND CT 仅为敏感性。
- BNP/NT-proBNP：支持 HF 概率和表型审计，不能单独确诊 DHF 或决定亚型；肾功能、房颤、PE、肺高压和脓毒症会影响解释。
- 血气和乳酸：反映低氧、酸碱紊乱和低灌注/循环恶化，属于 T0-T12 风险预测的候选变量，不是 DHF 或左/右心衰的单独确诊标准。
