# 任务报告：eMAR 提取范围扩大至 2,150 个 episode

日期：2026-09-24

状态：`approved_for_data_request_pending_actual_emar_delivery`

## 1. 本轮决定

根据研究负责人决定，eMAR 提取不再只覆盖 773 人主队列和 340 人 A+B 缺 C 边界层，而是扩大到四个高信息层，共 2,150 个 ICU episode：

| 人群 | n | 作用 |
|---|---:|---|
| A+B+C 主队列 | 773 | 研究一主队列和短期结局核对 |
| A+B 缺 C | 340 | 判断 C 域治疗证据是否漏记 |
| B+C 缺 A | 766 | 暂存心衰锚点缺失边界病例 |
| A+C 缺 B | 271 | 暂存失代偿证据缺失边界病例 |
| 合计 | 2,150 | eMAR 目标药物提取范围 |

扩大提取只增加资料储备，不改变任何主分析纳入标准。

## 2. 目标药物

主层：去甲肾上腺素、肾上腺素、血管加压素/垂体后叶素、去氧肾上腺素、多巴胺、多巴酚丁胺、米力农。
扩展层：异丙肾上腺素、左西孟旦、特利加压素。
静脉袢利尿剂层：呋塞米、托拉塞米。

静脉袢利尿剂只用于 C 域和治疗路径复核，不自动作为血流动力学恶化事件。

## 3. 需要的信息科字段

必须保留 episode 连接键、原始药名、规范化类别、实际执行时间、给药途径、剂量、浓度、速率、输注开始/停止时间、速率变化时间、执行状态和状态代码字典。

医嘱产生/停止、取药和术中记录不能替代实际执行；缺少执行状态或执行时间时编码为 unknown。

## 4. 研究分析边界

即使边界层发现实际执行的升压药或静脉袢利尿剂，也不能自动并入 773 人主队列。后续如需纳入，必须建立新版本操作性表型并重新做临床校准。研究三最终外部验证时间段若产生 2,150 人之外的新 episode，再追加这些 episode 的目标 eMAR。
