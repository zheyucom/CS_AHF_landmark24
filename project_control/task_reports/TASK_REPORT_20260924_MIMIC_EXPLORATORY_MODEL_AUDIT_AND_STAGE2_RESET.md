## 压力测试暴露的问题

1. **顺序不符合总方案。**研究一尚未完成，第二阶段变量和建模合同也未重新冻结。
2. **静态十变量信息量不足。**缺少心率、呼吸、SpO₂、尿量、T12 基线支持状态和 T0–T12 动态变化。
3. **NT-proBNP 不适合核心必备模型。**V4 仅 185/1,083（17.1%）可用；乳酸和 pH 的缺失率分别约 36.2% 和 30.2%。
4. **实际运行不符合既定方法。**使用普通 Fine–Gray 和训练样本中位数插补，没有完成惩罚化、部署兼容的缺失策略或完整流水线内重采样。
5. **结局主要由治疗行为构成。**V4 的 182 个目标事件中，136 个为血管活性药新启动（74.7%），必须进一步核对感染、镇静、围术期和 ICU 实践模式。
6. **内部验证不完整。**当前 bootstrap 以 stay 为单位，尚未审计同一患者多 episode；未完成患者级聚类、嵌套调参、校准截距/斜率、竞争风险决策曲线或时间验证。
7. **V3 不能作为验证集。**V3 是 V4 的严格重叠敏感性层，只能评价表型敏感性。

探索性数值（V4 表观 AUC 0.695、stay 级 bootstrap 校正约 0.675；V3 约 0.669）仅用于说明当前矩阵的信息上限，不评价最终模型成败。

## 对“轨迹＋机器学习”的处理

第二阶段不直接照搬大样本脓毒症深度学习方案。当前最适合的是把 T0–T12 动态摘要作为 M2 增量特征，与 M1 静态核心模型进行受控比较。

GBTM 只作为 MAP 等高频变量的敏感性层，必须核对类别稳定性和跨库可复现性。预测未来轨迹归属、端到端深度学习和网络虚拟干预暂不进入主方案，因为它们会改变研究问题或超出现有事件预算。
