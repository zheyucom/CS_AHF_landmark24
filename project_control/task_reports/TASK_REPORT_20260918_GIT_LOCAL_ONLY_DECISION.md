## 4. 解释要点

- Git 是版本控制系统，不等于网盘、数据库或自动同步工具。
- `.git` 保存本地历史、提交、分支、暂存区和差异记录。
- 远程仓库的价值是异地备份、跨设备同步、协作和恢复；不是 Git 正常工作的前提。
- 私有仓库是为了保护未发表研究方案、数据字典、内部流程和潜在敏感元数据；远程仓库也不应存放患者级数据。
- 空远程仓库可以避免本地已有历史与远端 README/.gitignore 初始历史产生无关合并冲突。

## 5. 后续本地操作

```bash
git status
git add <文件或目录>
git commit -m "中文说明本次变更"
git log --oneline --decorate -10
git diff HEAD~1 HEAD
```

首次提交前需要确认 Git 作者姓名和邮箱；暂不需要远程 URL、SSH key 或访问令牌。
