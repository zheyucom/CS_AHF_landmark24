# DHF 操作性表型跨库可迁移性与 BNP 映射审计

日期：2026-09-24  
状态：`audit_complete / V1_unchanged / V1.1_pending_source_validation`  
范围：研究一本院 DHF 表型、研究二 MIMIC 开发队列、研究三本院验证队列之间的角色和可迁移性。  

## 1. 结论

1. **NT-proBNP 从研究二“核心必备预测变量”移出，不等于从 DHF 操作性表型中移除。**表型证据回答“患者是否属于目标人群”，预测变量回答“已入组患者未来是否恶化”，用途不同。
2. **研究一不需要推倒重来。**当前 V1 的 `A+B+C` 概念结构保留，773 人结果作为可复现基线版本保留；在 BNP 项目映射和 eMAR 到位后，只需生成 V1.1 并重跑受队列成员变化影响的下游表格和关联分析。
3. **当前 V1 尚不能称最终临床金标准。**它是算法操作性表型，仍待分层临床校准；其中 179/773（23.2%）仅靠静脉袢利尿“医嘱代理”满足 C 域，对后续 eMAR 核验最敏感。
4. **真正需要补的是 BNP 映射，而不是删除 NT-proBNP。**现行数值型 C 域文件的 12,757 条记录全部为 `NT proBNP`。院内纵向检验导出另发现 156 条 `脑钠肽BNP`，但它们尚未完成项目身份、单位和跨就诊时间连接核验，不能直接并入阈值规则。
5. **研究一的 773 名患者本来就不进入研究二建模。**研究二使用 MIMIC 患者；研究一向研究二传递的是临床问题、表型概念、时间零点和数据可得性，不传递本院患者，也不能用本院死亡关联结果筛选 MIMIC 变量。

## 2. 当前 773 人的 C 域构成

记号：`N`=年龄分层 NT-proBNP rule-in，`E`=心超客观异常，`L`=T12 前静脉袢利尿医嘱代理。

| C 域组合 | 人数 | 占 773 人比例 | 当前解释 |
|---|---:|---:|---|
| 仅 L | 179 | 23.2% | 治疗医嘱代理层，待 eMAR 核实 |
| 仅 N | 110 | 14.2% | 单一利钠肽客观支持 |
| 仅 E | 84 | 10.9% | 单一心超客观支持 |
| N+L | 130 | 16.8% | 两域支持 |
| E+L | 110 | 14.2% | 两域支持 |
| N+E | 61 | 7.9% | 两项客观支持 |
| N+E+L | 99 | 12.8% | 三项支持 |

汇总：

- NT-proBNP rule-in：400/773；T12 前测过 NT-proBNP：427/773；
- 心超结果可用：417/773；心超异常支持：354/773；
- 静脉袢利尿医嘱代理：518/773；
- 至少两类 C 证据：400/773；仅一类 C 证据：373/773；
- 严格客观层 `A+B+(N 或 E)`：594 人；
- `A+B` 高敏感性层：1,113 人，其中 340 人当前无 C 支持；
- 主表型且满足严格 T12 风险集：558 人。

因此，773 人并非“全靠 NT-proBNP”筛出。即使 NT-proBNP 不进入研究二核心预测器，本院 V1 队列也不会因此失去逻辑基础。

## 3. BNP 映射缺口

当前数值型 C 域提取：

- `bnp_general_lab_evidence.csv` 共 12,757 行；
- 检验名称全部为 `NT proBNP`；
- 未出现单独 BNP 项目。

对两份院内纵向利钠肽导出进行结局盲法扫描后发现：

- `NT proBNP` 74,854 行；
- `脑钠肽BNP` 156 行；
- `脑钠肽BNP` 中，没有记录按“同一候选就诊号 + `[T0-24 h,T12)`”直接落入当前窗口；
- 101 个候选 ICU episode 在 T0 前 24 小时内可按患者号连接到另一就诊号的 `脑钠肽BNP` 记录；另 1 个为 T0 后跨就诊记录，按既定规则必须排除。

这 101 个候选 episode 中，12 个已经在当前主队列，只有 4 个属于 `A+B` 但因缺 C 尚未进入主队列；其余缺 A、缺 B 或两者均缺。4 个近边界病例的 BNP 数值中，描述性地看 2 个 `>=100`、1 个 `>=400`。这两个切点仅用于估计潜在影响，尚未获准作为项目阈值。也就是说，补齐 BNP 映射预计只会小幅改变 773 人，而不会推翻现有队列。

这提示 BNP 可能主要记录在急诊/前序就诊号。它是可修复的数据连接问题，但在确认以下内容前不能并入 C 域：

1. `脑钠肽BNP` 是否确为 BNP，而非另一 NT-proBNP 镜像或设备字段；
2. 单位是否稳定为 pg/mL；
3. 报告时间、采样时间和源就诊与 index ICU 的临床连续性；
4. BNP 与 NT-proBNP 使用各自阈值，禁止直接互换；
5. `<`、`>`、区间和不可解析值继续按三态处理，unknown 不得当阴性。

## 4. 第一阶段表型是否修改

### 4.1 不修改的概念主干

继续使用：

`A 当前心衰锚点 AND B 当前急性失代偿/充血证据 AND C 至少一项支持证据`

B 域继续必需。NT-proBNP、BNP、心超异常或利尿治疗均不能单独确认“本次急性失代偿”。

### 4.2 需要版本化完善的实现

不覆盖 V1，待源数据核验后建立 V1.1：

- `C_NTproBNP`：保留当前年龄分层 rule-in；
- `C_BNP`：新增独立项目映射和独立阈值，不与 NT-proBNP 合并成同一数值变量；
- `C_echo`：继续作为客观支持，记录异常类型和可见时间；“做过心超”本身不算阳性，正常 LVEF 也不能机械排除 HFpEF；
- `C_loop_executed`：eMAR 到位后作为执行级治疗证据；
- `C_loop_order_only`：保留为较低证据等级和敏感性层，不伪装成实际执行。

主分析、严格客观层、高敏感性层均保留。若 V1.1 改变队列成员，重新运行描述表、流程图和预先指定的低维关联分析；原 V1 结果留作可追溯敏感性结果，不删除、不静默覆盖。

## 5. 第一阶段如何影响第二阶段

允许传递：

- DHF 的临床概念和 A/B/C 证据域；
- T0、T12 和证据可见时间规则；
- 本院病例组合、检查习惯、数据缺失和部署可得性；
- 对跨库差异、选择偏倚和校准漂移的预设假设。

禁止传递：

- 用本院死亡 OR、P 值或变量重要性筛选 MIMIC 预测变量；
- 按本院死亡率、MIMIC AUC 或外部验证结果调整表型阈值；
- 在锁模前查看本院验证性能后反向改模型；
- 把医嘱当执行、把 unknown 当阴性。

研究二中 NT-proBNP 可继续用于 MIMIC 的 C 域表型，也可进入预先指定的生物标志物增量分析；因预测窗内可用率仅 185/1,083（17.1%），不作为跨库核心必备预测器。表型可用数与预测器可用数不同，是因为其时间窗、清洗合同和分析用途不同。

## 6. 研究三的队列处理

研究三不能简单把“研究一全部 773 人”直接称为外部验证集。模型冻结后，应在预先封存的本院较晚时间段重建验证风险集，并同时报告：

1. 本院丰富数据主表型；
2. 与 MIMIC 来源更一致的运输匹配层，例如 `A+B+(NT-proBNP rule-in 或 eMAR 实际静脉袢利尿)`；
3. 严格客观层和高敏感性层。

原样运输性能是主结果；不同表型层用于解释人群选择和可迁移性，不能按 AUC 选择“最好看”的一层。
