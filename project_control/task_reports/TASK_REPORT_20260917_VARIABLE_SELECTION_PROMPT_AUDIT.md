## 3. 已验证事实

Excel 的 597 条方案字段均非空，但内容并不等于字段级可复现合同：

- 590/597 条队列描述仍使用“按原文纳入排除”或“题名所述目标人群”；
- 557/597 条结局仍使用“按原文预先定义的主要和次要结局/评价终点”等泛化模板；
- 324/597 条缺失策略仍表示原文未明确或要求先按原文核对；
- 仅 1/597 条显式出现 MIMIC `itemid`；
- 17/597 条显式使用 Fine-Gray；
- 597/597 条包含运行前冻结、随机种子和训练折内预处理等通用约束。

《变量筛选.txt》的核心建议是：不采用单因素 P 值筛选；根据事件数控制模型复杂度；用临床合理性、文献和泛化能力共同决定候选变量；检查相关性和共线性；LASSO 只宜作为预筛选或降维工具。

与 DHF 最接近、可借鉴的 Excel 案例包括：

- T375：心衰早期预测，明确 0–6 小时窗口、最早测量、患者级划分和独立测试集；
- T115：心衰时间依赖模型，强调时间切分以及训练集内插补、缩放和编码；
- T226/T359：竞争风险分析，提醒区分目标事件、竞争事件和观察终止；
- T506：血管活性药升级，提供时间相关治疗升级定义的参考，但其因果推断框架不能直接移植为预测模型。

当前 DHF 文档已确认：T0/T12/T60 时间轴；T12 landmark；Fine-Gray 主模型；存活离开 index ICU 为竞争事件；DHF A/B/C 多域表型；心超不作为 MIMIC 主队列硬门槛；缺失、比较符号、医嘱执行代理和锁模外部验证规则。

## 4. 判断与影响

### 对变量筛选建议的判断

材料中“避免单因素 P 值筛选”和“事件数约束模型复杂度”适用于 DHF，但 EPV≥10 只能作为粗略提醒，不能作为 Fine-Gray 竞争风险模型的硬规则。正式模型应根据最终事件数、有效自由度、收缩需求和 Riley 样本量框架确定复杂度。

LASSO 不应自动成为最终变量筛选器。DHF 应先按临床域、跨库可迁移性、时间可获得性和数据质量形成低维候选集；LASSO 若使用，必须限制在训练折内，并预先登记为探索性或敏感性分支。

VIF、相关矩阵和 Spearman 可用于识别冗余，但不能机械地以 VIF>5 删除变量。应预先规定变量域和替代关系，例如血压、严重度评分、肾功能和乳酸派生指标之间的选择规则。

### 对 Prompt 的判断

Excel Prompt 的结构可作为检查清单，但不能直接替代 DHF 项目合同。当前 DHF Prompt 的研究逻辑比 Excel 模板更完整；尚未完全封口的是执行层细节，包括：

- 每个变量的 schema/table/field/itemid、单位、聚合和重复规则；
- index ICU stay 的唯一选择算法；
- DHF A/B/C 逐条判定及四态证据编码；
- T12 后目标事件、竞争事件、观察不完整的状态机；
- 医嘱代理与执行级治疗记录的分层；
- 最终事件数对应的参数上限和变量域选择；
- 运行版本、输入哈希、seed、折索引和停止/阻塞规则。

## 5. 对开题和论文写作的帮助

Prompt 对开题有帮助，但应转写为研究合同和方法章节，而不是把“AI Prompt”作为方法本身。适合进入开题/论文的内容包括：研究对象、时间轴、DHF 操作性表型、变量数据字典、结局状态机、缺失处理、模型开发和外部验证规则。

适合放入补充材料的内容包括：逐变量字段映射、SQL/伪代码、队列流转表、缺失矩阵、模型配置、随机种子、软件版本、运行登记和未实现条件。

## 6. 新增或确认的研究决策

1. Excel 工作簿定位为漏项检查和复现性审计参照，不逐字复制到 DHF 项目。
2. DHF 采用两层 Prompt：项目研究合同 + 字段级执行 Prompt。
3. 主模型变量不采用单因素 P 值筛选；优先临床域、可迁移性和事件数约束。
4. LASSO 仅在预先登记的训练折内使用，并作为探索性/敏感性方法，不能替代临床预设模型。
5. VIF 仅用于诊断冗余，不作为唯一删变量标准。
