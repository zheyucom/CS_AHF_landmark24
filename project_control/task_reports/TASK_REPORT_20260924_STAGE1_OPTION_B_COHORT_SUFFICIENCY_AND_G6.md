# 任务报告：研究一方案 B、队列充分性与 G6 描述性分析

日期：2026-09-24
状态：`G6_DESCRIPTION_COMPLETE_T0_FACTOR_FREEZE_PENDING`

## 1. 结论先行

1. **773 人不算少，不需要改变三阶段研究方案。** 它足以支持本院 DHF 临床现状描述和一个严格受限的预后关联分析。
2. 真正限制是 **62 例院内死亡**，不是 773 的总人数。按预先登记的每 15 个事件最多 1 个有效自由度，调整模型上限为 4 个有效自由度；不支持广泛危险因素筛选，也不支持再开发一个死亡预测模型。
3. `A+B+C` 可能牺牲部分敏感度，但不能因为想扩大样本就放宽。主队列继续为 773；严格客观层 594；`A+B` 高敏感性层 1,113，只作敏感性与误分类审计。
4. 近边界病例不是一批可以直接补进来的“漏诊 DHF”。必须区分证据未采集、证据已采集但不支持，以及存在替代诊断三种情况。
5. eMAR 到位前不妨碍完成本院死亡负担和 G6 描述性分析；eMAR 后续用于升级短期治疗事件的执行证据，并以版本化方式审计 C 域，不静默重写 V1 主队列。

## 2. 方案 B 冻结内容

- 主分析人群：本院 `A+B+C` 算法操作性 DHF 表型总体队列，773 人；
- 时间零点：index ICU 入科 `T0`；
- 主结局：同次住院病案首页确认的院内全因死亡；
- 结局数：死亡 62，非死亡出院 711，unknown 0；
- 主关联框架：收缩 Logistic/Firth Logistic；
- 有效自由度上限：4；
- 允许进入主分析的因素：T0 已知或不会被住院后过程改变的预先指定因素；
- 禁止：单因素 P 值筛选、逐步回归、AUC 最优化、第二个死亡预测模型、用研究一结果筛 MIMIC 变量。

T12 继续用于本院短期照护路径描述、MIMIC 动态预测开发及模型冻结后的本院外部验证。

## 3. 队列是否足够

主队列院内死亡率为 62/773，即 8.021%，Wilson 95% CI 为 6.307%–10.150%。该精度足以描述本院死亡负担。研究一定位为描述性研究加低维预后关联，因此 773 人满足当前目的。

如果把研究目标改成大规模变量筛选、复杂机器学习或再次开发预测模型，62 个事件明显不足；正确做法是限制问题和自由度，而不是放宽表型制造更多样本。

## 4. A+B+C 是否造成漏诊

8,385 名来源候选的八种域交集如下：

| 交集 | n | 当前角色 |
|---|---:|---|
| A+B+C | 773 | 主操作性表型 |
| A+B、缺 C | 340 | 最高优先级潜在假阴性层 |
| B+C、缺 A | 766 | 心衰锚点缺失近边界审核层 |
| A+C、缺 B | 271 | 失代偿证据缺失近边界审核层 |
| 仅 A | 651 | 不纳入主表型 |
| 仅 B | 1,289 | 不纳入主表型 |
| 仅 C | 859 | 不纳入主表型 |
| 三域均不支持 | 3,436 | 不纳入主表型 |

`A+B` 高敏感性层合计 1,113 人，其中新增的 340 人不能整批并入：

- 300/340 在 T12 前没有可用 NT-proBNP，40/340 已测但未达到年龄分层 rule-in；
- 280/340 没有可用心超结果，60/340 有结果但未满足异常标准；
- 340/340 均无有效静脉袢利尿医嘱代理；
- 333/340 同时出现替代诊断提示。

因此，这 340 人同时包含“客观证据不可用”和“已有证据但不支持”的病例，也高度富集替代诊断。它只能作为高敏感性/临床校准层，不能被称为 340 个漏诊病例。

补充盲法审核包已生成 100 例：B+C 缺 A 60 例、A+C 缺 B 40 例；与既有 290 例审核样本不重叠，抽样及审核包均不含死亡/结局字段。临床参考标准尚未填写完成，因此当前仍称“算法操作性表型”。
