# 2026-09-28 DHF表型AI全量预审与人工审核流程重制

## 结论

上一版把“分层校准样本”按抽样层顺序直接交给临床医生，且没有在表首明确290例中只有120例来自算法阳性层，导致前30例全部落在`algorithmic_unknown`层。研究者连续审核到大量非DHF病例并非773例主队列PPV极低的直接证据，而是抽样呈现和审核工作流设计错误。

本轮已改为：AI读取全部290例的结构化标志、T0前24小时至T12的NT-proBNP、T0附近文书和检查证据，先做五级预审分诊；医生只优先审核算法/AI冲突、时间冲突、未知层和分层随机质控样本。AI标签只用于排序和二阶段抽样，不能冒充临床金标准。

## 为什么不能让AI直接替代医生

将时间对齐AI结果与前30例人工标签交叉后，6例人工`DHF_yes`均被AI判为`likely_no/clear_no`。这不是允许AI自动排除的证据，而是发现了两个需要裁决的问题：

1. 原始A/B证据摘要可能含全住院期或T12后信息，而AI主标签只允许T12前证据；
2. 部分人工阳性评论依赖单纯EF降低、极高NT-proBNP或慢性心衰史，未明确写出当前急性失代偿B域；另一些病例则有明确肺水肿但被规则A域漏掉。

因此“AI审核会与人工大致一样”目前未被数据支持。AI适合做证据预填、明显模板排除、优先级排序和误入机制定位；临床参考标准仍需医生裁决。

## 已定位的主要误入机制

1. A域：风险告知、术后并发症列表、APACHE模板、既往/慢性心衰、问号诊断和全住院期后验诊断误作T12前当前心衰锚点。
2. B域：肺炎、ARDS、肺栓塞、吸入、卒中后呼吸衰竭等可解释湿啰音、低氧和呼吸困难；单一湿啰音/水肿/胸闷特异度不足。
3. C域：轻度瓣膜反流、左室肥厚、慢性心腔扩大或单纯EF降低不能证明当前DHF；正常EF也不能排除HFpEF。
4. 治疗代理：静脉袢利尿医嘱不等于执行，也可能用于容量管理、肾衰或围术期液体平衡。
5. 时间轴：全住院期出现的急性心衰不能倒灌进T0/T12风险集；T12后新发AHF应进入独立扩展研究。

## 对773例和第一阶段的影响

- 773例继续是工作版算法候选队列，尚不能称临床DHF队列，也不能据此冻结第一阶段最终样本量。
- 低NT-proBNP只影响极少数病例；当前更大的风险是A/B证据时间对齐和治疗代理-only层。
- 179例治疗代理-only层在eMAR到位前宜降为敏感性层；严格客观层优先，但也必须完成A/B临床校准。
- 第一阶段不需推倒重来，但死亡关联分析、照护路径和论文主结果必须等待最终表型与T0/T12时间轴冻结后重跑。
