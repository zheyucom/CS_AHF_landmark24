## 3. 不建议照搬的 4 点

1. **不要照搬 19 小节固定骨架。** 它是为"MIMIC-IV + 单生物标志物 → 死亡"这类同质研究设计的；本项目的核心难点是 landmark 时间合同、竞争风险、操作性表型判定，粒度完全不同。照搬会产出大量与课题无关的模板段落（典型的"敏感性分析命中 597/597、实际只有 302 篇"式词频污染）。
2. **不要照搬通用占位符的作风。** 它的结局字段 84% 是"按原文预先定义的主要和次要结局"，这在本项目是不可接受的——每个字段都必须落到自己的可执行口径，否则闸门 G2 无法通过。
3. **不要照搬"标准答案隔离"的字面做法。** 它是单盲复现评测设计（597/597 带"不得发送给实验 AI"的保密标记）；本项目是原创研究，没有现成答案可对照。**但可以借它的思想**：在看见最终性能前把预期区间/预期方向写下来并封存，等价于一次轻量的预注册，用来对抗选择性报告（PROBAST+AI 分析域）。
4. **不要追求"批量生成"。** 它靠模板引擎在 597 篇上保持一致；本项目只有 1 个研究，收益在**单步深度**，不在批量。14 个步骤写透，比 597 行同质 prompt 更有价值。

```

【输入】

- 现状证据：本院 NT-proBNP 截断比例 女 3.5%(857/24,705)、男 4.4%(2,181/50,149)，
  形态 `>25000` / `<20` / `<20.00`，且「检验结果数值」列为空

【执行顺序】
```

## 5. 统一执行规则（本项目版 7 条）

在 Excel 的 6 条通用护栏基础上，按本项目风险加 1 条、并按竞争风险语境改写：

1. **原始数据只读。** 所有纳排、单位换算、异常值处理、变量派生、插补、编码、筛选、建模与评价均通过脚本完成，不允许手工改数或手工改表。
2. **时间不可逆。** 任何 T12 之后的信息不得进入预测特征；任何结局发生后的信息不得进入协变量；测量频率本身视为严重度代理，必须单独审计。
3. **上游不可被下游结果反向改写。** 六步逻辑链是单向的：表型/资格/结局冻结后，若最终性能不理想，只能新增预设敏感性分支，不能回头改定义。
4. **划分与外层折一经产生即固定。** 插补器、标准化器、编码器、变量选择器与超参数搜索只在训练折内拟合；验证/测试折不得参与选变量、调参或模型选择。
5. **随机操作在运行前一次性固定种子**，并保存拆分映射与折索引。计划中未写明的设置不得"试到满意为止"；未报告项必须在运行前写入表 D 并标记为冻结假设。
6. **全流程同一数据版本、变量定义、参照组。** 发现字段缺失、定义冲突或方法无法唯一确定时，停止该分支并记录缺口，不自行替换变量或方法。
7. **验收标准先于结果。** 表 C 的达标条件必须在看见最终性能前填写并记录时间戳；解封后不得放宽达标条件，只允许如实报告偏差并解释。

## 7. 文献卡回填规范（当前 0/15，性价比最高的一步）

**实测**：Obsidian 库的 15 张文献卡，`templates/literature-note-template.md` 定义了 `sample_size / event_count / event_rate / index_time / lookback_window / prediction_horizon / outcome_definition / predictor_availability / missing_data_strategy / class_imbalance_strategy / calibration_reported / clinical_utility_reported / external_validation_sites` 共 13 个可复现字段——**实际非空计数全部为 0/15**。

同时，模板的 12 章结构在实作中被压缩为 7 章（一句话结论 / 研究问题与创新 / 设计与属性分类 / 主要结果 / 偏倚与适用性 / 对当前课题的沉淀 / 证据锚点与关联）——**恰好被省掉的正是第 08 章「偏倚、适用性与可复现性」**，而其中的 8.4「可复现材料：代码 / 变量字典 / 模型参数 / 补充材料 / 数据访问条件」是判断"这篇能不能被我照做"的关键章节。

**建议动作**（低成本、直接对接 Excel 的"事实层"思路）：对 15 篇中**与建模直接相关的 8 篇**（R004/R019/R020/R021/R022/R037/R055/R056）回填：

- 必填 7 个：`sample_size`、`event_count`、`outcome_definition`（操作性定义，不是结局名）、`index_time`、`prediction_horizon`、`missing_data_strategy`、`calibration_reported`
- 选填 2 个：`external_validation_sites`、`class_imbalance_strategy`

回填后你会得到一张**可直接横向比较的"方法学参数矩阵"**——它的作用与那份 Excel 的"事实层"完全一致：把散文变成字段，才能发现自己方案里哪一格是空的（例如"别人的校准都是怎么报的，我报的够不够"）。

**另需修正的一处口径**：`CS_AHF 文献知识地图.md` 第 9 行的研究合同是"约 n=2,424、事件 334（13.78%）、elastic-net 为主模型"，而 `study_definition_v5` §3.4 与 `STATISTICAL_ANALYSIS_PLAN` §4.1 已把主模型改为 **Fine-Gray**、队列口径改为多域 DHF 待冻结。知识地图这一行是旧合同残留，应加注"已由 v5.7 + SAP v1.0 取代"。

## 9. 一句话总结

那份 Excel 的价值不在"597 篇"和"19 小节的 prompt 文案"，而在于它证明了一件事：**可复刻性不是靠把方法写全，而是靠 (a) 把事实字段化、(b) 把缺口显式冻结、(c) 把验收标准先于结果封存。**

本项目 (a) 已经做到且质量更高；缺 (b) 的**分步绑定**和 (c) 的**整张表**。把 §4 的四张表建起来，你的流程就有资格被称为"每一步细化且可复刻"——而且比那份 Excel 更完整，因为你会补上它自己都缺的冻结配置登记与 AI 判读留痕。
