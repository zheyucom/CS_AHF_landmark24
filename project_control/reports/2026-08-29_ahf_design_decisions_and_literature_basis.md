# AHF 表型、建模规模与敏感性分析设计说明

日期：2026-08-29  
状态：历史 AHF 设计修订稿。ESC 2026 DHF 方案已改以 `2026-08-29_ESC2026_DHF_implications_and_protocol_update.md` 为当前依据；本文件保留审计和 EPV 推理。

## 1. 先回答当前三个问题

### 1.1 什么是“严格 AHF”

这里的“严格 AHF”不是临床金标准，也不是声称数据库中每位患者都在 ICU 入科前被医生实时确认了急性心衰。更准确的名称是：

> **pre-T0 operational AHF phenotype**：本次住院最终存在急性/急性加重心衰诊断锚点，并且 ICU 入科前存在可追溯的时间戳心衰相关证据。

当前操作定义同时要求：

1. 急性或急性加重 HF ICD，且 HF 诊断序位 `<=5`；
2. `admittime <= evidence_time < intime`；
3. 至少一项实际 IV 袢利尿剂 eMAR 或 NT-proBNP `>=300 pg/mL`。

这套定义借鉴了急性心衰指南和急性呼吸困难研究所强调的“临床表现/充血证据 + 医师诊断 + 生物标志物 + 治疗过程”的多域证据原则，但**不是某篇文献原样规定的 MIMIC 筛选公式**。MIMIC-IV 中症状、体征、医生首次诊断时间和影像信息并不完整，所以必须明确称为操作性表型，并将表型误分类列为局限性。

### 1.2 为什么要做 650 例低维输入

650 例不是先拿来“试验”、之后再把 5,555 例完整建模。若导师确认论文研究对象必须是 AHF，那么 650 例就是目标人群，模型应在这类人群上开发。

当前 650 例有 66 个事件。原来的 45 个预测器只有 `66/45 = 1.47` 个事件/变量，远低于传统 EPV=10 的经验警戒线，也会带来系数不稳定、过拟合和内部验证乐观偏倚。因此需要：

- 在建模前冻结少量、临床有依据的候选变量；
- 目标为约 5-6 个有效参数，而不是把 45 个变量直接搬入；
- 所有插补、标准化、变量选择和收缩均在训练折内完成；
- 以 bootstrap 或重复交叉验证评估不确定性，不能只报告一组表观性能。

“650 例低维模型”和“5,555 例 45 特征模型”回答的是两个不同问题，不能把后者的性能当作前者的最终性能。5,555 例 broad operational cohort 可以保留作比较/敏感性分析；若 650 例低维模型仍不稳定，应把结果定位为探索性或可行性分析，而不是包装成可直接临床使用的预测模型。

EPV=10 只是保守经验规则，不是现代预测模型的充分样本量标准。最终应同时报告事件数、有效参数数、收缩策略和校准不确定性，并参考 Riley 等人的预测模型样本量框架。

### 1.3 BNP-only、PE、最近 24 h 和双证据是什么

它们不是默认的主队列排除标准，而是用来检验表型误分类和时间口径影响的**预设敏感性分析/审计分层**。

| 分析 | 目的 | 当前作用 | 不能怎样表述 |
|---|---|---|---|
| 排除 BNP-only | 检查结果是否依赖单一、非特异性生物标志物 | 650 例中剩 146 例、9 个事件，主要做描述性稳定性检查 | 不能说这是指南规定的 AHF 排除标准 |
| 排除 PE | 减少肺栓塞/右心负荷升高造成 NT-proBNP 升高而混入的风险 | 诊断编码基础的替代诊断敏感性 | 不能把所有 AHF 患者常规排除 PE；PE 可与 AHF 共存，且 ICD 时间不精确 |
| 最近 24 h | 检查“住院早期很久以前的证据”是否使表型过宽 | 378 例、34 个事件 | 不是临床诊断标准，只是时间窗敏感性 |
| 双证据 | 提高表型特异性，检验单一证据域的影响 | loop+原始 NT-proBNP 只有 43/1；loop+年龄分层 rule-in 为 36/1，不能稳定建模 | 不能宣称已有统一文献规定这一组合 |

### 1.4 `NT-proBNP >=300` 的准确定位

在急性呼吸困难场景，NT-proBNP `300 pg/mL` 更接近用于**排除急性心衰的高敏感性阈值**，并不是单独的 rule-in 或确诊阈值。肾功能不全、年龄、房颤、肺栓塞、肺高压、脓毒症和右心负荷均可能使 NT-proBNP 升高；肥胖等情况还可能使数值偏低。

因此本项目不能写成“NT-proBNP >=300 确诊 AHF”。它只能作为：

- 与急性 HF ICD 锚点结合的支持性证据；
- BNP-only 表型的单独报告对象；
- 排除 BNP-only 的敏感性分析触发条件。

本轮年龄分层 rule-in 审计结果如下：

| 口径 | stays | events |
|---|---:|---:|
| 当前 pre-T0 operational 候选 | 650 | 66 |
| 年龄分层 NT-proBNP rule-in（<55:450；55-75:900；>75:1800） | 484 | - |
| 实际 IV loop eMAR | 146 | - |
| loop + 年龄分层 rule-in | 36 | 1 |
| loop 或年龄分层 rule-in | 594 | 61 |

年龄分层阈值的来源是急性心衰诊断研究/指南中的 rule-in 思路；将其迁移到 MIMIC 前仍需核对 assay、单位和检验项目。它是审计和敏感性口径，不替代临床诊断。

## 2. ACS、肾衰和其他疾病如何处理

### 2.1 不建议把所有共病都排除

ACS/AMI、CKD/AKI、房颤、COPD 和肺炎既可能是 AHF 的诱因，也可能是并存疾病。若看到这些 ICD 就全部排除，会删掉真实临床中最重要的 AHF 人群，并降低外部推广性。当前审计中 strict 候选包含 ACS/AMI 159 例、AKI/CKD/透析 448 例，不能据此直接判定“不是 AHF”。

推荐：主分析保留，作为共病描述、亚组/交互探索或调整变量；在解释 NT-proBNP 时明确其混杂路径。

### 2.2 PE 和明确的非心衰主导诊断

PE 更适合作为预设敏感性排除，因为右心负荷和肺高压可能升高 NT-proBNP，而利尿剂也不具有 AHF 特异性。但仅凭最终诊断编码会有时间和误分类限制，所以结果应写成“diagnosis-code-based PE exclusion sensitivity”，不能写成排除了所有 PE。

若后续获得 pre-T0 放射科文本，建议优先识别“肺水肿/充血/胸腔积液”等证据，同时识别 PE、肺炎/ARDS 等替代诊断。文本规则命中需要人工抽样复核，不能直接当作金标准；出院小结不能替代 T0 前实时诊断时间，也不能进入预测器。

## 3. 推荐的三层 AHF 表型

| 层级 | 定义 | 用途 |
|---|---|---|
| Broad operational | HF ICD 锚定 + 较宽早期 HF 相关证据 | 保留 5,555 例历史/比较路线；不能称临床确诊 AHF |
| Pragmatic strict | acute/acute-on-chronic HF ICD、序位 `<=5` + pre-T0 实际 IV loop eMAR 或 NT-proBNP `>=300` | 650/66；当前最适合作为 AHF 主队列候选 |
| High-specificity two-domain | 例如 loop + age-rule-in，或 loop/biomarker + pre-T0 影像充血证据 | 主要做表型验证/描述；当前事件太少，不强行建模 |

如果导师要求论文标题和主分析必须明确写 AHF，建议先按 pragmatic strict 队列重建低维模型；如果低维模型不能稳定估计，则诚实改为“AHF 操作性表型的探索性模型”，或将 broad cohort 作为主分析并把 strict 队列作为主要敏感性分析，不能两者混称。

## 4. 文献依据及其边界

| 文献 | 可直接支持的内容 | 不能直接支持的内容 |
|---|---|---|
| McDonagh et al., 2021 ESC HF guideline, doi:10.1093/eurheartj/ehab368 | AHF 诊断需要症状/体征、充血或影像及支持性检查的综合判断；NT-proBNP 不是脱离临床背景的单独确诊 | 不规定 MIMIC 的 ICD 序位、eMAR、时间窗组合 |
| Januzzi et al., 2006, doi:10.1093/eurheartj/ehi631 | NT-proBNP 在急性失代偿 HF 中的诊断和短期预后价值；阈值应结合临床背景 | 不支持 `>=300` 单独确诊 AHF |
| Maisel et al., 2002, doi:10.1056/NEJMoa020233 | BNP 可辅助急性呼吸困难中的 HF 鉴别 | 不支持仅凭 BNP 入组为确诊 AHF |
| Mueller et al., 2004, doi:10.1056/NEJMoa031681 | BNP 应用于急性呼吸困难的评估和管理，强调临床整合 | 不规定本项目的敏感性分析组合 |
| Peduzzi et al., 1996, doi:10.1016/S0895-4356(96)00236-3 | 事件数相对预测变量数过少会增加过拟合风险，支持控制模型复杂度 | EPV=10 不是唯一或充分的现代样本量标准 |
| van Smeden et al., 2019, doi:10.1177/0962280218784726 | 预测模型样本量不能只机械依赖 EPV，应考虑事件率、过拟合和性能精度 | 不能为 650/66 自动证明 45 个变量可接受 |
| Collins et al., TRIPOD, 2015, doi:10.1136/bmj.g7594 | 预测模型的透明报告，包括人群、预测变量、结局、验证和缺失处理 | 报告规范本身不保证表型或模型无偏倚 |

答辩时建议使用这句话：

> 文献支持的是多域证据整合和表型敏感性分析的原则；本研究的 ICD 序位、时间窗和 eMAR/NT-proBNP 组合，是在 MIMIC 字段限制下预先定义的可复刻操作化方案，而不是声称存在一条文献原样规定了该筛选公式。

## 5. 当前应冻结的研究决策

1. 主模型仍为 Fine-Gray；1 h person-period 为补充模型；ICU 内死亡进入 composite 主事件；alive ICU discharge 为竞争事件。
2. AHF 主队列暂定为 650/66 的 pragmatic strict phenotype，但在导师确认前标为“主候选”，不把它写成金标准。
3. 650 例主模型先做低维、强收缩、折内预处理；不直接使用 v3.3 的 45 个预测器。
4. broad 5,555/454 保留为历史/比较分析，不覆盖、不回填为 strict AHF 结果。
5. BNP-only、PE、最近 24 h、双证据均列为敏感性/审计，不列为未经导师确认的默认排除标准。
6. BigQuery Note radiology 验证完成前，不把文本规则命中用于扩大主队列；完成后报告覆盖率、时间窗合规率和人工抽样阳性预测值。
