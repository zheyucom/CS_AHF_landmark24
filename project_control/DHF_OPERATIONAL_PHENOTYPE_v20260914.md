# DHF operational phenotype v0.3 (2026-09-14)

本版本用于锁定研究定义和审计流程，所有自动标签仍是 draft/weak label，不能作为临床金标准。最终队列必须在人工裁决后冻结，并保留每条证据的来源、时间和原文片段。

2026-09-15校正：现有原文及医嘱可用于预审核和派生表构建，不等待eMAR补提；按用户授权先由AI预审核，只将仍未决临床问题交用户。是否已经完成独立临床金标准审核另行记录。最新实际进度见`RESEARCH_DASHBOARD.md`，文献核准信息见`METHODS_EVIDENCE_MAP_20260915.md`。

## 1. 研究人群与时间窗

院内已导出且按床旁心超条件选择的成人 index ICU 候选分母为 8,385 人（男 5,543，女 2,842；排除患者 9204020），不是全院所有成人 ICU 分母。每位患者按一次 index ICU encounter 进入候选；同一次就诊的多次 ICU episode 单独切分 episode，只有与当前 episode 的入/出 ICU 文书和 SOAP 时间一致的 episode 才可作为 index episode。

`T0` 优先使用护理记录或入住 ICU/入 ICU 文书中描述“由××进入 ICU”的事件时间；`T0` 不使用文书创建时间。`T12` 为 `T0+12 h`。床旁心超报告窗口为 `[T0-24 h, T0+12 h)`；报告时间是出报告时间，不等同于检查执行时间。若执行时间缺失，必须在方法中注明，并将时间不确定性作为敏感性分析。

院内主分析采用 **echo-supported DHF ICU cohort**：成人、有效床旁心超报告、且在同窗内满足下述 DHF operational phenotype。心超不是 DHF 的充分条件，也不把胸片作为硬纳入条件。

## 2. DHF 判定域

### A. HF anchor（必须有）

至少满足一项患者特异性证据：

1. 入院诊断、会诊或 SOAP 明确写出急性心衰、心力衰竭、心功能不全、心源性休克或心肌病，并指向本次 ICU episode；
2. 明确结构性心脏病/严重瓣膜病/显著心室功能异常，同时有本次 episode 的充血或失代偿证据；
3. MIMIC 中由可追溯的诊断、症状体征和治疗记录共同满足上述语义。单独的病危告知、评分模板、鉴别诊断清单或“可能出现心衰”不算 anchor。

### B. 失代偿/充血域（至少一项）

- 患者特异性的呼吸困难、端坐呼吸、夜间阵发性呼吸困难、颈静脉怒张、肺部湿啰音、外周水肿或低氧恶化；
- 胸片或胸部 CT 明确肺血管充血、间质性/肺泡性肺水肿或与充血一致的双侧胸腔积液；
- 与心源性机制相符的急性低灌注/血流动力学恶化。

“有肺炎/ARDS/吸入、出血、创伤、术后或脓毒症”等替代解释时，必须记录其是否足以独立解释当前表现，不能仅凭一个症状或影像词排除/纳入。

### C. 支持域（记录但不单独确诊）

- BNP/NT-proBNP：按年龄、肾功能、房颤和急性危重状态解释；单独升高不构成 DHF；
- 心超：EF、右室功能、舒张功能、瓣膜病、肺高压及 IVC/充盈线索；心超异常是强支持证据，但需与 A/B 同窗关联；
- 胸部影像：用于肺充血支持及替代诊断审计；非胸部影像标记为 `non_chest`/`indeterminate`，不能当作肺充血阴性；
- 袢利尿剂、血管活性药、无创/有创通气或液体管理：结合患者特异性文书与同窗医嘱区间作为管理支持；废除/取消医嘱排除。按用户确认目前使用医嘱执行代理，不称真实eMAR；基础治疗持续存在不自动等于治疗强化。

## 3. 分层与冻结规则

- `confirmed_dhf`：A + B，且至少一个 C 域或明确心源性管理强化；替代解释不能完全解释表现。
- `probable_dhf`：A + B，但 C 域/时间或替代解释仍有小缺口；用于敏感性分析，不进入主锁定队列，直到人工裁决。
- `not_supported`：无患者特异性 A，或存在充分替代解释且无 B/C 的心源性组合。
- `unknown`：证据冲突、时间无法定位或文本缺失；不得按阳性处理。

主队列冻结条件：每例保存A/B/C、替代解释、证据时间、来源与裁决状态。按用户授权完成全量AI预审核，已解答病例不重复索取确认；仅剩余未决临床病例交用户。当前规则分层不作为正式冻结或独立临床金标准；论文中报告自动表型时须给出独立参照抽样校准与标签误差评估，不能以同一规则重复运行代替验证。

## 4. MIMIC 与院内的可比性

MIMIC使用多域表型，心超作支持及敏感性层；不要求心超可减少该检查硬门槛造成的选择，但不能消除其他选择偏倚。院内采用echo-supported cohort，报告从8,385已选择成人候选到最终DHF的流程。本研究主事件是T12后ICU血流动力学恶化或ICU内死亡的复合结局；活着离开index ICU是竞争事件，至T60仍在ICU且无事件者为行政删失。院内使用现有医嘱/护理/文书先重建各组成，再评估与MIMIC结局测量的可比性；不能从药品总剂量推算NEE持续升级。
