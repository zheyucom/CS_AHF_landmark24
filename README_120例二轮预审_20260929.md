# 120例算法阳性DHF二轮预审：打开顺序

## 1. 现在只打开这个文件

`positive120_AI_deep_review_and_physician_adjudication_20260929.xlsx`

先进入工作表“医生裁决病例”。这里只保留52例：38例疑难病例和14例确定性质控病例，不需要重审120例，更不需要继续盲审290例。

## 2. 每例只填写六列

1. 医生DHF总标签：`DHF_yes / DHF_no / indeterminate`
2. 医生A域：`yes / no / unknown`
3. 医生B域：`yes / no / unknown`
4. 医生C域：`yes / no / unknown`
5. 医生T0核对：`correct / incorrect / uncertain`
6. 医生裁决备注：用一句话写主要依据或冲突

前五列已设置下拉框。

## 3. 其他文件用途

- `positive120_second_pass_ai_review_v1.csv`：120例完整AI预审和关键原文，供追溯；
- `positive120_physician_adjudication_subset_v1.csv`：52例精简审核表的CSV版本；
- `positive120_second_pass_summary_v1.json`：机器可读汇总；
- `TASK_REPORT_20260929_POSITIVE120_SECOND_PASS_AI_REVIEW.md`：结论、误纳机制和队列处置门槛。

## 4. 重要边界

AI预审不是临床金标准，表内“初步下界/上界”不能写成正式PPV。完成医生裁决后，才计算分层PPV、95%CI，并决定773例队列收紧还是整体重建。
